# CNN Image Classification
A Convolutional Neural Network (CNN) project for classifying images into six categories.
## Classes
- Buildings
- Forest
- Glacier
- Mountain
- Sea
- Street
## Model

The model was built using TensorFlow and Keras.

The project includes:

- Image preprocessing
- CNN model construction
- Model training
- Training and validation accuracy/loss visualization
- Test evaluation
- Confusion matrix
- Prediction on a new image
## Dataset

The project uses the Intel Image Classification dataset.

The dataset is not included in this repository because of its size.

## Results

**Test Accuracy: 80%**

The trained model was also tested on a new mountain image that was not part of the original dataset.

## Technologies

- Python
